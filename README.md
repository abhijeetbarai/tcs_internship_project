# 📊 Employee Attrition & Performance Analysis

🚀 Data Analytics | 📈 Power BI Dashboard | 🤖 Machine Learning

---

## 📌 About The Project

This project focuses on analyzing employee attrition using the IBM HR Analytics dataset. The main objective is to identify the factors affecting employee turnover and provide meaningful business insights using Python, Machine Learning, and Power BI.

The project includes:
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Machine Learning Prediction
- Interactive Power BI Dashboard

---

## 🎯 Project Objectives

✔ Analyze employee attrition trends  
✔ Identify factors causing employees to leave  
✔ Build interactive visual dashboards  
✔ Predict attrition using Machine Learning  
✔ Generate business insights & recommendations  

---

## 🧠 Key Insights

- Employees with lower salaries show higher attrition
- Sales department has the highest employee turnover
- Younger employees leave more frequently
- Poor work-life balance impacts retention
- Employee satisfaction strongly affects attrition

---

## 💡 Recommendations

- Improve employee salary structure
- Increase employee engagement activities
- Enhance work-life balance policies
- Focus on employee satisfaction programs
- Reduce workload in high attrition departments
